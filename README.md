# AI Interview Chatbot

AI 面接練習用の Web アプリプロトタイプです。OpenAI API を任意で使えます。アカウント、企業、ES、面接ログなどのアプリ内データは、標準ではブラウザの `localStorage` に保存します。Firebase設定を追加すると、GoogleログインとFirestoreクラウド保存を使えます。

## 起動方法

Node.js 18 以上が入っていれば、追加の依存インストールなしで起動できます。

```powershell
npm start
```

起動後、ブラウザで以下を開きます。

```text
http://localhost:8000/
```

別のポートで起動する場合:

```powershell
$env:PORT=8080
npm start
```

## チェック

JavaScript の構文確認:

```powershell
npm run check
```

## 使い方

1. `ES管理` でアカウント、企業、ES設問、ES回答を登録します。
2. `面接設定` で企業、面接タイプ、質問カテゴリ、AI面接官タイプ、質問数を選びます。
3. `面接を開始` すると、保存済みES、企業情報、過去の質問・回答ログを使って質問が生成されます。
4. 回答を送信すると、回答評価、追加確認の理由、次の質問が作られます。
5. 面接終了後に、総合フィードバックと履歴詳細を確認できます。

AI面接官タイプで `ランダム` を選ぶと、開始時に面接官タイプがランダムに決定されます。事前に聞かれ方を読みすぎず、実戦に近い練習をしたい場合に使います。

## 実装済み

- アカウント、企業・ES管理、面接設定、面接チャット、最終フィードバック、履歴画面
- `localStorage` によるアカウント、企業、ES、面接ログ、選択中アカウントの保存
- OpenAI APIキー設定画面、接続テスト、ローカルサーバー経由のOpenAI呼び出し
- OpenAIを使った面接質問生成、回答評価、深掘り質問生成、最終フィードバック生成
- Googleログイン、Firestoreクラウド保存、localStorageからFirestoreへの移行
- 過去の質問・回答・不足点を使った重複質問の抑制
- 議題カバレッジ管理による、未確認テーマ優先の質問生成
- 回答が不十分な場合だけ理由を示して深掘りする次問制御
- 面接設定での質問ソース選択（AIによる動的生成 / 定番質問集から出題）。定番質問集モードではカテゴリに応じたキュレーション済みの定番質問を順番に出題し、使い切ると自動的にAI生成に切り替え（深掘り質問は引き続きAIが生成）
- 回答入力欄でのSTAR法（状況・課題・行動・結果）を意識させるガイド表示
- ランダムAI面接官モード
- ES設問・回答・文字数・カテゴリ・ステータス管理、文字数制限超過時の保存ブロック
- 企業・ES・アカウントの編集・削除・複製（企業/アカウント削除時は紐づくESや履歴も連動して削除、削除前に確認ダイアログを表示）
- 保存済み企業を起点に、その企業に紐づく全ESを使った面接開始
- 質問数設定、回答送信、深掘り質問、会話タイムライン、途中終了
- 質問読み上げ、音声入力、一時録音のセッション内確認
- 録画映像を使った表情・視線・姿勢の簡易傾向分析（顔位置の安定度、映像の変化量。ブラウザ内処理のみで外部送信なし）
- モック採点と最終フィードバック
- 面接途中でのヘッダー操作やタブを閉じる操作に対する離脱確認（未保存の回答を誤って失わないようにするガード）
- 履歴一覧（アカウントごとに分離）、詳細表示、個別削除・全削除（確認ダイアログあり）、質問テーマと追加確認理由の表示
- 履歴の「同じ設定で再練習」「詳細をコピー」「JSONでエクスポート」、企業・カテゴリでの絞り込み、日付・点数での並び替え
- 履歴画面での達成バッジ表示。練習回数・連続日数・スコア到達/改善に応じたバッジを、既存の面接ログから毎回計算して表示（新規の永続データは持たない軽量な機能）
- レスポンシブ CSS

## Google連携

GoogleログインとFirestore保存を使う場合は、[docs/google-firebase-setup.md](docs/google-firebase-setup.md) に沿ってFirebaseプロジェクトを作成し、`ai-interview-prototype/firebase-config.js` にFirebase Web app configを設定してください。未設定のままでも、従来どおりlocalStorageのみで利用できます。

## 質問生成の方針

このアプリは、保存済みESを見るだけでなく、面接中の質問・回答・評価結果も使って次の質問を決めます。

- 既に十分答えた内容は繰り返さない
- 不足や未確認情報がある場合だけ、その理由を示して深掘りする
- 深掘りが不要な場合は、未確認のテーマへ進む
- 面接官タイプは聞き方や厳しさを変える役割にし、議題の偏りはカバレッジ管理で抑える
- 面接設定の「質問の出題方法」で `AIによる動的生成`（既定）と `定番質問集から出題` を選べる。定番質問集モードではカテゴリに応じたキュレーション済みの定番質問を順番に出題し、使い切ると自動的にAI生成へフォールバックする。深掘り質問は出題方法の設定によらず常にAIが生成する

## OpenAI API設定

画面右上の `AI設定` から、使用者自身の OpenAI APIキーを入力します。`OpenAIを使う` を選び、接続テストが成功すると以下でAIを利用します。

- 面接質問生成
- 回答評価と深掘り質問生成
- 最終フィードバック生成

APIキーはローカルサーバーの `/api/openai` 経由でOpenAIへ送信されます。`APIキーをこのブラウザに保存する` を有効にした場合のみ `localStorage` に保存します。共有PCでは保存しない運用を推奨します。

## 表情・視線・姿勢の傾向分析

カメラ録画中の映像から、「顔位置の安定度」と「映像の変化量」という2つの簡易的な指標を算出します。外部のAI画像解析APIやクラウドサービスは一切使用せず、分析処理自体はすべてブラウザ内（クライアントサイドJavaScript）で完結します。録画映像そのものが外部に送信されることはありません。分析結果（スコア）は他の面接ログの項目（回答テキストや評価点など）と同様に扱われ、Google連携でFirestoreクラウド保存を有効にしている場合はその同期対象に含まれます（localStorageのみで利用している場合は端末外に出ません）。

- 顔位置の安定度: `window.FaceDetector`（Shape Detection API）に対応したブラウザでのみ算出します。現在の主要ブラウザの多くは未対応のため、表示されないことがあります。
- 映像の変化量: フレーム間のピクセル差分から算出し、ブラウザの対応状況に関わらず利用できます。

いずれも簡易的な参考情報であり、表情・視線・印象などを断定的に評価するものではありません。
